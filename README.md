# SCADA Signal Database (cis.db)

База данных сигналов SCADA — каталог технологических объектов, их параметров и привязка к сигналам телемеханики.

## Структура проекта

```
io/
├── conf.yaml        # DDL, триггеры, SQL-запросы (INSERT/UPDATE/SELECT/EXPORT)
├── make_db.py       # Создание БД и импорт справочников из CSV
├── exp.py           # Экспорт данных в CSV и обновление справочников
├── common.py        # Утилиты: чтение conf.yaml, подключение к SQLite
├── cis.db           # SQLite база (генерируется)
├── ref/             # Исходные CSV-справочники для импорта
│   ├── sys.csv
│   ├── dpt.csv
│   ├── dpe.csv
│   ├── dp.csv
│   └── grp.csv
├── ref/out/         # Экспортированные CSV
└── ref/upd/         # CSV для обновления данных
```

## Схема БД

```
sys ──< dpt ──< dp
          │
          └──< dpe >── grp (тип, единица, формат, точность)
                 │
sg ──< sg_rel >── dp + dpe
 │
 ├── cfg_addr        1:1  адрес телемеханики (coa, ioa, type)
 ├── cfg_alarm       1:N  конфигурация алармов (уставки, deadband, приоритет)
 │     └── ref_limit_type  справочник типов уставок (NORMA, LL, L, H, HH, ...)
 ├── vl_cur          1:1  текущее значение (кеш)
 └── vl              1:N  история значений
```

### Таблицы

| Таблица | Назначение |
|---------|-----------|
| `sys` | Системы (СДКУ, ЦСПА, ...) |
| `dpt` | Типы технологических объектов в рамках системы |
| `dpe` | Свойства/параметры типа (давление, состояние, аварии) |
| `dp` | Экземпляры объектов (конкретная задвижка, агрегат) |
| `sg` | Сигналы телемеханики (независимый справочник) |
| `sg_rel` | Связь сигнала с объектом и свойством (sg → dp + dpe) |
| `grp` | Группы параметров, единицы измерения, форматы |
| `cfg_addr` | Адреса телемеханики для сигналов |
| `cfg_alarm` | Конфигурация уставок алармов |
| `ref_limit_type` | Справочник типов уставок |
| `vl_cur` | Текущее значение сигнала (кеш) |
| `vl` | История значений сигналов |
